# LomoHealth – Carnet de santé numérique Togo

Plus jamais un enfant ne manquera son vaccin à cause d’un carnet perdu.

## Stack
- Mobile : Flutter (iOS + Android)
- Backend : Laravel 11 API
- QR + Offline first

## Installation rapide
```bash
# API
cd api && composer install && php artisan serve

# Mobile
cd mobile && flutter pub get && flutter run
